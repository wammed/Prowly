This document records the provenance, design-review history, and IP due-diligence process for the **Prowly** application icon.

> **Scope:** This is a project provenance and due-diligence record. It is not a legal opinion, trademark clearance, or guarantee that no third-party rights are implicated.

## 1. Asset & Provenance

- **Application:** Prowly
- **Purpose:** Full-featured, AI-integrated TUI Git & GitHub client.
- **Generation method:** AI-assisted image generation and iterative design refinement using Google Gemini.
- **Current design language:** Flat, matte dark charcoal background with a solid geometric monogram and subtle emerald/mint glowing accents, consistent with the application suite design system (Fluffy, Toodle, Rooney, Waddle).
- **Current visual concept:** A geometric monogram of the letter **P** incorporating the application's core concepts: **Git branch branching/commit nodes** and an **embedded terminal prompt / AI indicator**.

## 2. Design Review History

### Initial concept & Suite Alignment

The Prowly icon was designed to maintain visual harmony alongside existing sister projects:
- **Fluffy** (Letter "F" + monitor display & play metaphor);
- **Toodle** (Letter "T" + clock dial & rising sun);
- **Rooney** (Letter "R" + split-view panes & rope structure);
- **Waddle** (Letter "W" + terminal prompt `>`).

The primary challenge was ensuring consistent brand cohesion (dark squircle/matte canvas, clean typography, sub-label) while avoiding conceptual collision with existing developer tools and sister applications.

### Revision & Differentiation

The design centers on a distinctive monogram combining:
- The letter **P** (Prowly);
- Internal **Git DAG / branch lines and commit nodes**;
- A subtle terminal/AI interactive prompt (`>_`) embedded in the counter of the "P".

## 3. Similarity Review

### Sister Applications

| Reference | Observation | Project Action |
| :--- | :--- | :--- |
| **Fluffy** | Uses letter "F" with display/media motif. | Distinct letterform and Git graph branching metaphor. |
| **Toodle** | Uses letter "T" with clock and sunrise glow. | Differentiated by Git node topology and mint/emerald accent. |
| **Rooney** | Uses letter "R" with split-pane ribbon geometry. | Differentiated by single-loop "P" construction and commit node visuals. |
| **Waddle** | Uses letter "W" with terminal chevron prompt. | While both incorporate terminal aesthetics, Prowly's primary structure is a Git branch tree within "P". |

### Third-Party & Open Source Ecosystem

| Reference | Observation | Project Action |
| :--- | :--- | :--- |
| **GitLens** | Well-known Git visualization tool featuring commit graph nodes. | GitLens employs a multi-node matrix grid without letterform framing. Prowly constructs an explicit letter "P". |
| **Perforce (P4 / Helix Core)** | Prominent version control branding using the letter "P". | Perforce uses solid directional polygon blocks. Prowly uses branching stroke paths and commit vertices. |
| **Processing / p5.js** | Developer-facing geometric "P" logo. | Processing uses layered blue geometric block forms. No Git graph or terminal iconography is present in Processing. |
| **Prowler** | Security CLI tool with phonetic naming similarity. | Prowler uses detective/mascot or badge imagery. Visual designs share zero common elements. |
| **Mainstream Git Clients (GitKraken, Fork, Tower, Lazygit)** | Kraken mascot, physical fork icon, tower illustration, or retro text boxes. | Prowly avoids figurative/mascot illustrations in favor of an abstract geometric monogram. |

## 4. Current Design Rationale

The final monogram represents the core functional pillars of the application:
- **P** → Prowly;
- **Git Branch & Commit Nodes** → Hybrid Git engine, DAG history visualization, interactive rebase, and worktree integration;
- **Prompt & Glow Accent** → Omnipresent AI assistant and modern TUI environment.
