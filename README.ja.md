## 概要

**Prowly** は、Rust、Ratatui、Crossterm で構築された次世代のターミナルユーザーインターフェース (TUI) Git & GitHub クライアントです。ターミナルで作業を完結させるエンジニアのために設計されており、超高速なローカルGit操作、深いGitHubワークフロー統合、安全第一のソフト破棄バックアップ、そして常に手元で支援するAIコパイロットを完全に統合しています。

キーボードのショートカット操作はもちろん、直感的なマウス操作（クリック、スクロール、右クリックコンテキストメニュー）にも完全対応しており、Linux、macOS、Windows のいずれの環境でも快適で美麗な開発体験を提供します。

## 主な機能

- ⚡ **ハイブリッド Git アーキテクチャ**: 高速なインプロセス `git2` によるメモリ内検査と、高度なGit CLI処理の自動フォールバックを両立。
- 🛡️ **ソフト破棄（Soft-Discard）安全設計**: 変更の破棄 (`discard`) やリセットを行っても、コードを永久に失うことはありません。実行前に自動的に一時バックアップ（セーフティースタッシュ）が作成されます。
- 🤖 **全面統合 AI コパイロット（BYOK対応）**:
  - どの画面からでも即座に呼び出せるコンテキスト連動モーダル (`Ctrl+A`)。
  - Conventional Commits 準拠のコミットメッセージ自動生成 & コミット前コードレビュー (`Ctrl+R`)。
  - GitHub Actions CI 失敗時のログ解析と原因特定・修正提案。
  - 要約と変更内容を含んだ Pull Request ドラフト本文の自動生成。
  - AI による競合コードのインテリジェントマージ（両ブランチの意図を汲み取った結合）。
  - 自然言語リクエストから Git コマンドへの自動翻訳とリスク判定 (`Safe` / `Caution` / `Dangerous`)。
- 📂 **ディレクトリマップ & 一括ステージング**: リポジトリ全体の変更ツリーを可視化し、フォルダ単位での一括ステージング・アンステージングが可能。
- 📜 **Git Graph・コミット履歴 & タイムマシン機能 (`2` / `h`)**:
  - `git log --graph` を解析した視覚的な Git Graph ツリーマップ表示（上下キーで接続線を自動スキップしコミット間を軽快に移動）。
  - ポインタ先端が指すコミットを正確に選択する高精度マウスクリック判定 & Diffプレビュー上のマウスホイールスクロール。
  - 選択コミットの詳細メタ情報（作成者、相対日時、ハッシュ）およびリアルタイム diff プレビュー。
  - コミット操作メニュー & 右クリックコンテキストメニュー: チェックアウト (`c`)、新規ブランチ作成 (`b`)、チェリーピック (`p`)、リバート (`r`)、AI相談。
  - **タイムマシン機能 (`t`)**: 過去のコミットを選択することで、それ以降のコミットをすべて無効化し過去コミットを最新状態として復元（実行前に自動で安全バックアップブランチ `backup/timemachine-...` を作成しデータ消失ゼロを保証）。
  - コミットハッシュのクリップボードコピー (`y`)。
- 🌲 **ネイティブ Git ワークツリー管理**: スタッシュ退避なしで別ブランチの作業ディレクトリを瞬時に作成・切り替え・整理。
- 🐙 **第一級の GitHub 統合**:
  - **課題 (Issues) ビュー (`3` / `i`)**: オープン/クローズ一覧、ステータス、ラベル、コメント数表示、本文 Markdown プレビュー、ブラウザ即時オープン (`o`)、タブ切り替え時の自動ロード、および `r` キーによる明示的リロード。
  - プルリクエスト一覧、詳細閲覧、ローカルへのチェックアウト。
  - GitHub Actions ワークフロー履歴とログストリーミング。
  - Dependabot やセキュリティアラートの通知確認。
  - レートリミット保護ガードと TTL インメモリキャッシュ。
-  **左右2ペイン式リポジトリ切り替えモーダル (`[  Open Repo ]` / `o`)**:
  - **左ペイン (Discovery)**: サブディレクトリ内の Git リポジトリを自動探索してブランチ名付きで一覧表示（`a` で全フォルダ表示トグル）。
  - **右ペイン (Recent & Actions)**: 重複パスを省いたクリーンな履歴一覧、Tabキー自動補完付きパス直接入力、リモートクローンプロンプト (`c`)、および `git init` 新規初期化 (`i`)。
  - マウスカーソル位置に応じた左右ペインの独立ホイールスクロール対応。
  - **前回作業リポジトリの自動記憶 & 起動時自動復帰**（設定モーダルで ON/OFF 切替可能）。
- 🚀 **パフォーマンス & UI 最適化**:
  - マウス移動イベント (`MouseMove`) のフィルタリングにより、カーソル移動時の無駄な再描画と CPU 負荷を徹底排除。
  - 大量ファイル環境でも快適に動作するよう、Git status / diff での未追跡 (untracked) ディレクトリ再帰スキャンを無効化。
  - 狭い端末幅でも崩れないトップバーのパス自動省略（truncate）と、ヘッダーピルのホバーハイライト。
  - Changes ビューでの `[ Stage All ]` / `[ Unstage All ]` ボタンのマウスクリック操作対応。
- ⚔️ **ビジュアル・コンフリクトリゾルバ**: `Current`（自分側）と `Incoming`（相手側）を並べて比較し、ワンキーで選択、または AI スマートマージで解消。
- 🔀 **クイック・インタラクティブ・リベース**: Vim のバッファを直接編集することなく、直前のコミット群を視覚的にスカッシュ (`squash`)、リワード (`reword`)、フィックスアップ (`fixup`)。
- 🧭 **3層積層コマンドパレット (`:` / `F1` / `Ctrl+P`)**:
  - 第1層（Prowly組み込み操作の高速ファジー検索 & 全件仮想スクロール）
  - 第2層（110+標準Git CLIサブコマンドカタログ・カテゴリバッジ表示）
  - 第3層（引数・オプション直接入力 & Tabフラグ自動巡回補完）
  - パンくずリスト、Esc/Backspace階層ロールバック、直打ちジャンプ、破壊的操作（force push, hard reset等）の2段階確認セーフティガードを完備。
- 📝 **Markdown 簡易プレビュー (`m` / コンテキストメニュー / コマンドパレット)**:
  - README や PR 本文、ドキュメントなどの Markdown ファイルを、アクティブなカラーテーマと調和したリッチなターミナル内モーダルで閲覧。
  - 見出し、太字、斜体、インラインコード、コードブロック（言語タグ枠線付き）、チェックリスト、箇条書き、引用、リンク、水平線に対応。
  - ページスクロール (`PgUp`/`PgDn`)、先頭/末尾ジャンプ、クリップボードコピー (`y`) を完備。
- 🧪 **200+ の網羅的自動テスト & CI/CD インフラ**:
  - 全35ファイル・200件超の自動テスト（ユニット、結合、UIクリック判定、セキュリティ、実Gitシナリオ、110+コマンドマトリクス）。
  - GitHub Actions による全ブランチ自動ビルド・リント・テスト実行 (`.github/workflows/ci.yml`)。
  - Git コミット直前の自動検証フック (`.githooks/pre-commit`) とファイル保存時自動テストウォッチャー (`scripts/watch_tests.sh`) を完備。
  - Git コマンド実行時の環境変数完全隔離アーキテクチャ (`clean_git_command`)。
- 🎨 **厳選された全21種類のカラーテーマ**: Catppuccin、Tokyo Night、Gruvbox、Nord、Dracula、Solarized、One、Rosé Pine、Monokai Pro、Synthwave '84、Everforest Dark。
- 🌐 **完全なバイリンガル対応**: 英語と日本語をワンキー (`l`) で即時切り替え。
- 🚀 **アプリランチャー & デフォルトターミナル自動起動**: FreeDesktop 仕様の `.desktop` エントリとアイコンを自動登録し、システムのデフォルトターミナルで起動。

## インストール & デスクトップランチャー統合

### Linux / FreeDesktop 環境（推奨）

リポジトリをクローンし、付属のインストールスクリプトを実行してください:

```bash
git clone https://github.com/wammed/Prowly.git
cd Prowly
./scripts/install.sh
```

#### `install.sh` の処理内容:
1. 最適化されたリリースバイナリをビルド (`~/.local/bin/prowly`)
2. スケーラブルなSVGアプリアイコンを登録 (`~/.local/share/icons/hicolor/scalable/apps/prowly.svg`)
3. `~/.local/share/applications/prowly.desktop` に `.desktop` ファイルを生成:
   ```ini
   [Desktop Entry]
   Name=Prowly
   Exec=~/.local/bin/prowly
   Icon=prowly
   Terminal=true
   Type=Application
   Categories=Development;RevisionControl;ConsoleOnly;
   ```
4. **結果**: お使いのデスクトップ環境（GNOME, KDE Plasma, Rofi, Wofi, Albert など）のアプリランチャーに Prowly のアイコンが表示され、クリックすると**システムのデフォルトターミナル**で自動起動します！

アンインストール:
```bash
./scripts/uninstall.sh
```

### macOS 環境 (Apple Silicon M1+ / Intel)

```bash
chmod +x ./scripts/install.sh
./scripts/install.sh
```

### Cargo による手動ビルド

```bash
cargo build --release
cp target/release/prowly ~/.local/bin/
```

### リポジトリ & ディレクトリ切り替えモーダル (ヘッダークリック または `o`)
ローカルリポジトリ探索とリモートGit操作をシームレスにつなぐワイドな左右2ペインモーダル：
- **左ペイン (Repository Discovery)**: 現在地およびサブディレクトリ内の `.git` リポジトリを自動探索してブランチ名付きで一覧表示。`[a: All Dirs / g: Git Only]` で通常ディレクトリの表示も切り替え可能。
- **右ペイン (Recent & Actions)**: 最近開いたリポジトリ（パスの重複を省いたスッキリしたリポジトリ名表示）、Tab補完付き直接パス入力窓、`[ i ] Init Repo Here`、および専用URL入力プロンプト付きの `[ c ] Clone Remote Here`。

| 操作 | 機能 |
|:---|:---|
| `Tab` (パス入力欄) | **パスの自動補完 (TAB補完)**（一致候補の共通接頭辞補完および連続補完） |
| `Enter` (パス入力欄) | 入力されたパスのリポジトリを開く |
| `←` / `→` (Left / Right) | 左ペイン (Discovery) と 右ペイン (Recent / Path) 間のフォーカス移動 |
| `↓` / `↑` | フォーカス中のペイン内での項目選択・移動 |
| `Enter` (Discovery内) | 選択したリポジトリを開く（`..` で親ディレクトリへ移動して再探索） |
| `Enter` (Recent内) | 選択した最近のリポジトリを開く |
| `c` (入力欄外) | **Clone Remote Repository** プロンプト起動（URLを入力してEnterでクローン実行） |
| `i` (入力欄外) | 現在/指定ディレクトリで **git init** を実行してそのまま開く |
| `a` (入力欄外) | Gitリポジトリのみ表示 ⇄ 全ディレクトリ表示のトグル切り替え |
| `d` / `x` / `Delete` | 選択中の最近のリポジトリ履歴を削除 |
| マウスホイール | マウスカーソル位置に応じて左ペイン (Discovery) または右ペイン (Recent) を個別スクロール |
| マウスクリック | リポジトリ選択・オープン、`[ i ] Init`、`[ c ] Clone`、`[ ✕ ]` で履歴削除 |

### マウス操作 & 端末エミュレータ互換性（右クリック競合について）

Prowly はクリックでのファイル選択、チェックボックス切り替え、ホイールスクロール、ボタン操作など、マウス操作に完全対応しています。

> [!NOTE]
> **右クリックと端末エミュレータの競合仕様**
> 
> - **端末エミュレータによる動作の違い**:
>   - **TUI 親和的端末 (Alacritty, Kitty, WezTerm, Foot 等)**: アプリへのマウスパススルーが標準で有効なため、ファイル一覧などを**右クリック**して直接コンテキストメニューを開けます。
>   - **デスクトップ標準端末 (GNOME Terminal, XFCE Terminal 等の VTE 系、Windows Terminal の既定設定)**: 端末ウィンドウ側のネイティブ GUI メニュー（コピー・貼り付け等）が OS のイベントループで優先的に消費（横取り）されるため、アプリ側へ右クリックイベントが送信されない、または端末側のメニューと重なる現象が発生します。これは子プロセス側から制御できない端末エミュレータ固有の仕様・制限です。
> - **Prowly の全端末互換アプローチ**:
>   - すべての端末環境で右クリックに依存せず100%確実にコンテキスト操作を行えるよう、画面上に**左クリック対応の `[ 󰍜 Menu ▾ ]` ボタン**を配置しています。
>   - 右クリックが端末に横取りされる環境でも、**左クリックまたは `m` キー**により、すべての機能（エディタ起動、パスのコピー、破棄など）を確実に呼び出せます。

## AIコパイロット設定 (BYOK)

Prowly は **Bring-Your-Own-Key (BYOK)** 方式を採用しており、主要な LLM プロバイダーと直接連携します:

- **OpenAI** (`gpt-4o`, `gpt-4o-mini`)
- **Anthropic** (`claude-3-5-sonnet-20241022`)
- **Google Gemini** (`gemini-1.5-flash`, `gemini-1.5-pro`)
- **Ollama** (ローカルモデル: `llama3.2`, `mistral` など)
- **カスタム / OpenAI 互換エンドポイント**

### 環境変数の設定
シェル設定ファイル (`~/.bashrc`, `~/.zshrc` など) で API キーを設定します:

```bash
export OPENAI_API_KEY="sk-..."
# または
export ANTHROPIC_API_KEY="sk-ant-..."
# または
export GEMINI_API_KEY="AIza..."
```

### 設定ファイル (`~/.config/prowly/config.toml`)
```toml
[ui]
theme = "catppuccin_mocha"
language = "ja"
nerd_fonts = true

[ai]
provider = "openai"
model = "gpt-4o-mini"
timeout_secs = 30
auto_review = true

[github]
token = "ghp_..."
```

### ローカル Ollama の利用設定
ローカルで動作している [Ollama](https://ollama.com/) を利用する場合、API キーは不要です。

```toml
[ai]
provider = "ollama"
```

> ※ OpenAI 互換エンドポイント（`/v1`）経由で接続したい場合は、`provider = "custom"` を指定し `api_base = "http://127.0.0.1:11434/v1"` を設定してください。
